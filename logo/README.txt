Положите сюда картинку для иконки приложения (TgCheck.exe):

  logo.png  /  logo.ico  /  logo.jpg  (имя файла любое)

* Лучше всего квадратная PNG 256x256 или больше, с прозрачным фоном.
* PNG/JPG при сборке автоматически превращается в .ico со всеми размерами (16-256 px).
* Если файлов несколько — берётся первый .ico, иначе первый .png, затем .jpg/.bmp.
* Картинка также показывается на экране входа и в заголовке окна.
* Если папка пустая — exe собирается без своей иконки (стандартная иконка Windows).
