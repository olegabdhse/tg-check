# TG Check

Десктоп-приложение (C# / .NET 8 / WPF) для просмотра своего профиля Telegram и подарков,
с продажей обычных подарков за звёзды. Вход по номеру телефона или по QR-коду.
Подключение идёт напрямую к серверам Telegram через официальный MTProto API
(библиотека [WTelegramClient](https://github.com/wiz0u/WTelegramClient)), без ботов и сторонних сервисов.

## Возможности

- **Чаты**: вкладки «Все» и «Личные», архив (кнопка рядом с вкладками), поиск по своим чатам и глобальный поиск людей/каналов.
  В чате: история с подгрузкой при прокрутке вверх, отправка (Enter, Shift+Enter — новая строка), ответ (двойной клик или меню),
  редактирование (↑ в пустом поле — последнее своё), удаление, копирование, сохранение файлов, просмотр фото,
  стикеры, превью видео/GIF, голосовые и документы, «печатает…», галочки прочтения, новые сообщения в реальном времени.
- **Чужие профили**: поле «Открыть профиль» сверху (@username, t.me/…, tg://user?id=…, ID), клик по аватарке/имени
  в чате или по отправителю подарка. Видны информация, фото и подарки, кнопка «Открыть чат».
- **Игнор-лист** (`TG_IGNORE_IDS` в .env): подарки, чат, сообщения в группах и профиль этих людей скрыты, будто их нет.
- **Автообновление через GitHub Releases** (см. ниже).

- **Вход**: по номеру (код из Telegram / SMS, облачный пароль 2FA, почта) или по QR-коду
  (Настройки → Устройства → Подключить устройство), 2FA после QR тоже поддерживается.
- **Профиль**: аватар, имя, юзернеймы, ID, телефон (скрыт, показывается по кнопке), «о себе»,
  день рождения и возраст, Premium/верификация, статус в сети, баланс звёзд и TON, уровень рейтинга,
  личный канал, коллекционный статус, бизнес-адрес. Клик по строке копирует значение.
- **Подарки**: все подарки профиля с картинками (анимированные `.tgs` рендерятся через Skia/Skottie,
  у уникальных — фон и узор, как в Telegram). Фильтры: все / обычные / уникальные / можно продать / скрытые,
  сортировка, поиск. Карточка подарка: отправитель, дата, сообщение, модель/фон/узор с редкостью, номер,
  тираж, оценка, срок продажи, ссылка `t.me/nft/...`.
- **Продажа за звёзды** (`payments.convertStarGift`): одного подарка — из карточки, или нескольких сразу —
  кнопка «Продать за звёзды» → отметить → «Продать выбранные». Всегда с подтверждением.

## Ключи Telegram (.env)

1. Откройте <https://my.telegram.org> и войдите по номеру своего аккаунта (код придёт в Telegram).
2. Выберите **API development tools**.
3. Заполните форму (один раз на аккаунт): *App title* — например `TgCheck`, *Short name* — `tgcheck`
   (5–32 латинских символа), *Platform* — `Desktop`, остальное можно не заполнять. Нажмите **Create application**.
4. Скопируйте **App api_id** (число) и **App api_hash** (32 символа).
5. Создайте файл `.env` по образцу [.env.example](.env.example):

```env
TG_API_ID=1234567
TG_API_HASH=0123456789abcdef0123456789abcdef
```

Где программа ищет `.env`: рядом с `TgCheck.exe`, затем в родительских папках (поэтому при запуске из
IDE подойдёт `.env` в корне проекта), затем в текущей папке. Переменные окружения с теми же именами
имеют приоритет над файлом.

Если Telegram у провайдера работает плохо или заблокирован, добавьте в `.env` прокси
(или просто включите VPN):

```env
TG_PROXY=https://t.me/proxy?server=1.2.3.4&port=443&secret=ee...   # MTProxy
TG_PROXY=socks5://127.0.0.1:1080                                   # SOCKS5 (можно логин:пароль@хост:порт)
```

При старте приложение делает до 4 попыток подключения; подробности ошибок — в логе.

> `api_hash` — секрет: не публикуйте его и не коммитьте `.env` (он уже в `.gitignore`).
> Сессия хранится в `%LOCALAPPDATA%\TgCheck\session.dat`, зашифрованная Windows DPAPI: скопированный
> на другой компьютер файл не расшифруется. Кнопка «Выйти» завершает сессию на серверах Telegram.

## Обновления через GitHub Releases

1. Создайте **публичный** репозиторий на GitHub (например `owner/tg-check`) и запушьте туда проект (хотя бы один коммит).
2. Пропишите его в [Directory.Build.props](Directory.Build.props): `<UpdateRepo ...>owner/tg-check</UpdateRepo>`.
3. Создайте токен: GitHub → Settings → Developer settings → Fine-grained tokens → доступ к репозиторию, *Contents: Read and write*.
4. Выпуск версии:

```bash
powershell -ExecutionPolicy Bypass -File .\release.ps1 -Version 1.2.0 -Notes "Что нового"
```

(перед этим `$env:GITHUB_TOKEN = "github_pat_..."`). Скрипт соберёт exe с этой версией, создаст релиз `v1.2.0` и прикрепит `TgCheck.exe`.
Приложение при запуске проверяет последний релиз; если версия новее — показывает «Доступна версия … · Обновить»,
скачивает exe, закрывается, подменяет файл и запускается заново (`.env` рядом не трогается).

## Сборка

Нужен [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0).

```bash
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

Результат — один файл `dist\TgCheck.exe` (вместе с ним кладётся `.env.example`, и `.env`, если он есть в корне).
Exe самодостаточный: на других ПК .NET ставить не нужно. Ключ `-FrameworkDependent` собирает маленький exe,
которому нужен установленный .NET 8 Desktop Runtime.

Запуск для разработки:

```bash
dotnet run --project src/TgCheck.App
```

### Иконка (папка `logo`)

Положите в [logo/](logo/) картинку (`.png`, `.ico`, `.jpg`, `.bmp`; лучше квадратную PNG от 256×256) — при сборке
она станет иконкой exe (PNG автоматически конвертируется в многоразмерный `.ico`), а также появится на экране
входа и в заголовке окна. Нет картинки — exe собирается без своей иконки. Логика — в [build/Logo.targets](build/Logo.targets).

## Структура

```
src/
  TgCheck.Core/          — бэкенд, без UI
    Config/AppEnv.cs         чтение .env
    Services/TelegramService.cs  вход, профиль, подарки, продажа
    Services/ProtectedSessionStore.cs  сессия под DPAPI
    Services/TgErrors.cs     понятные тексты ошибок Telegram
    Media/MediaService.cs    скачивание и рендер стикеров подарков (+ дисковый кэш)
    Models/                  ProfileInfo, GiftItem
  TgCheck.App/           — интерфейс (WPF, MVVM)
    Themes/Theme.xaml        цвета и стили
    Views/                   экраны: вход, профиль, статус
    ViewModels/              логика экранов
build/                   — генерация иконки из logo/
logo/                    — сюда картинку для иконки
build.ps1                — сборка в dist/TgCheck.exe
```

UI обращается к Telegram только через `TelegramService` и модели из `TgCheck.Core.Models`, поэтому
дизайн можно менять или заменить целиком, не трогая бэкенд.

## Важно знать

- Продать за звёзды можно только **обычный** подарок и только в течение срока, который задаёт Telegram
  (обычно ~90 дней с получения; срок показан в карточке). Уникальные (NFT) подарки так не продаются.
- Продажа необратима: подарок пропадает из профиля, звёзды приходят на баланс.
- Логи (только предупреждения и ошибки): `%LOCALAPPDATA%\TgCheck\logs\tgcheck.log`, кэш картинок — `...\cache`.
